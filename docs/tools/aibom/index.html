aibom: detect shadow-AI inventory drift in a repository in AI agents

Offline AI bill of materials for a code repository. It answers "what AI is in this repo?" for reviews, audits, vendor questionnaires and AI-governance inventories (for example, the AI asset inventory that ISO/IEC 42001 and the NIST AI RMF expect), and it can fail CI when a new, undeclared AI component appears ("shadow AI").

What it detects

Offline AI bill of materials for a code repository. It answers "what AI is in this repo?" for reviews, audits, vendor questionnaires and AI-governance inventories (for example, the AI asset inventory that ISO/IEC 42001 and the NIST AI RMF expect), and it can fail CI when a new, undeclared AI component appears ("shadow AI").

Single Python file, standard library only, no network calls. It reads files; it never imports, executes or loads anything it finds.

Rules

CodeSeverityMeaning
AB01highModel file in a pickle-based format (.pkl, .pt, .ckpt, .joblib): loading it can run arbitrary code
AB02lowAI dependency not pinned to an exact version
AB03lowFloating model alias (gpt-4o, *-latest, *-preview, *-exp): behaviour can change under you
AB04mediumPlaintext http:// to a remote AI provider
AB05mediumAI SDK imported in code but not declared in any dependency manifest

Usage

python3 aibom.py path/to/repo                       # human-readable inventory + notes
python3 aibom.py . --json -o aibom.json             # machine-readable; also a baseline
python3 aibom.py . --cyclonedx --hash -o bom.cdx.json   # CycloneDX 1.6 (ML-BOM components, services)
python3 aibom.py . --baseline aibom.json --fail-on new  # CI: fail when new AI components appear
python3 aibom.py . --fail-on high                   # CI: fail on pickle model files

After pip install of the kit, the same options work as agentsec aibom …. Every tool also accepts --help and almost every tool accepts --json.

SARIF and CI

agentsec aibom path/to/input --json > aibom.json
# aibom does not yet emit SARIF; use --json and keep --fail-on for CI.

# GitHub Actions (composite action ships with the repo)
- uses: dunkleschitz/agentsec@v0
  with:
    tools: aibom
    paths: path/to/input
    fail-on: high

--sarif is not available on this tool yet (resultguard and toolpoison are reserved as good first issues). Use --json and a --fail-on exit gate instead.

Known limits

Heuristic scanner, not a security boundary. A clean result does not mean something is safe. All example secrets in this repository are fake.
