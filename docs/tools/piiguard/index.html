piiguard: detect PII in agent transcripts in AI agents

Offline PII / sensitive-personal-data scanner for AI agent transcripts and logs.

What it detects

Offline PII / sensitive-personal-data scanner for AI agent transcripts and logs.

Before you share a run, drop it into a ticket, or ship it to a log pipeline, piiguard checks whether emails, phone numbers, SSNs, payment cards, government IDs, bank details, dates of birth, home addresses, or medical record numbers leaked into messages or tool results. It can also write a redacted copy (--redact).

Standard library only. It never connects to a network.

Rules

RuleSeverityWhat it flags
PG01highEmail address
PG02highPhone number (NANP / simple international)
PG03criticalUS Social Security number (labeled or dashed; invalid area/group rejected)
PG04criticalPayment card PAN (Luhn + loose issuer prefix)
PG05highPassport / driver's-license / national-ID (labeled)
PG06highIBAN (MOD-97), ABA routing, bank account number (labeled / JSON keys)
PG07mediumDate of birth (labeled)
PG08mediumStreet / postal address heuristic
PG09mediumMedical record number / NPI (labeled)
PG10infoInventory of segments scanned (disable in CI with --disable PG10)

Usage

python3 piiguard.py transcript.json [more.jsonl dir/ -]
  --as-text           treat inputs as plain text (paragraph = segment)
  --disable RULE ...  skip rule ids (e.g. PG10 PG01)
  --json              machine-readable output
  --min-severity S    hide findings below S (default info)
  --fail-on S         exit 1 if any finding >= S (default high; any, none)
  --redact OUT        write redacted copy (file for one input, directory for many)
  --list-rules

After pip install of the kit, the same options work as agentsec piiguard …. Every tool also accepts --help and almost every tool accepts --json.

Example output

Flags SSN (PG03), card (PG04), email/phone (PG01/PG02), passport (PG05), bank fields (PG06), DOB/address/MRN (PG07–PG09); exit 1. (Those JSON fixtures are gitignored because they embed Luhn-valid demo PANs; always regenerate with make_examples.py.)

Email-only JSONL works without generation. --redact writes a copy with matches replaced by [REDACTED:PG0x:…] tokens.

examples/clean_openai.json is clean under --fail-on high (exit 0).

Captured against the bundled fixtures (fake data only):

SARIF and CI

agentsec piiguard path/to/input --sarif > piiguard.sarif

# GitHub Actions (composite action ships with the repo)
- uses: dunkleschitz/agentsec@v0
  with:
    tools: piiguard
    paths: path/to/input
    fail-on: high

SARIF 2.1.0 can be uploaded to GitHub code scanning. The composite action writes per-tool reports under agentsec-sarif/ by default.

Known limits

  • Heuristic regex + checksums. Novel formats, non-US national IDs without labels,

and non-Latin addresses are often missed; order IDs and random digit runs can false-positive — review snippets.

  • Card detection needs a Luhn-valid PAN with a plausible issuer prefix; truncated

or encrypted card tokens are invisible.

  • Bare 9-digit SSNs without dashes or a nearby label are ignored on purpose.
  • Only sees what was logged. Redaction rewrites text spans; it does not prove a

downstream system forgot the original.

  • A clean piiguard result does not mean the transcript is free of secrets — run

tracesweep for credentials.
