yolocheck: detect over-permissive coding-agent settings in AI agents

Offline, stdlib-only Python 3 CLI that audits coding-agent permission / autonomy settings files for risky over-permissioning: wildcard shell allows, interpreters and network tools on auto-approve, bypass / YOLO modes, disabled sandboxes, hooks that run curl | sh or ship your env to a server, filesystem scopes that include / or your home directory, and more. Each file gets a grade A–F.

What it detects

Offline, stdlib-only Python 3 CLI that audits coding-agent permission / autonomy settings files for risky over-permissioning: wildcard shell allows, interpreters and network tools on auto-approve, bypass / YOLO modes, disabled sandboxes, hooks that run curl | sh or ship your env to a server, filesystem scopes that include / or your home directory, and more. Each file gets a grade A–F.

Supported (best-effort) inputs:

HarnessFiles auto-discovered in directoriesWhat is evaluated
Claude Code.claude/settings.json, .claude/settings.local.json (pass ~/.claude/settings.json explicitly)permissions.allow/deny/defaultMode/additionalDirectories, hooks, statusLine, apiKeyHelper & other helpers, enableAllProjectMcpServers

Cursor (CLI-style permissions).cursor/cli.json, .cursor/cli-config.jsonpermissions.allow/deny with Shell(...)/Read(...)/Write(...), plus recognizable allowlist / yolo / auto-run keys

Files passed explicitly are recognized by content shape even with other names. JSONC (// and /* */ comments, trailing commas) is accepted.

Usage

yolocheck .                                   # discover settings files under the current repo
yolocheck ~/.claude/settings.json ~/.codex/config.toml
yolocheck . --min-severity medium             # hide low/info
yolocheck . --json > yolocheck.json
yolocheck . --sarif > yolocheck.sarif         # SARIF 2.1.0 for code-scanning UIs
yolocheck . --fail-on medium                  # CI gate
yolocheck . --disable YC17,YC05
yolocheck --list-rules

After pip install of the kit, the same options work as agentsec yolocheck …. Every tool also accepts --help and almost every tool accepts --json.

SARIF and CI

agentsec yolocheck path/to/input --sarif > yolocheck.sarif

# GitHub Actions (composite action ships with the repo)
- uses: dunkleschitz/agentsec@v0
  with:
    tools: yolocheck
    paths: path/to/input
    fail-on: high

SARIF 2.1.0 can be uploaded to GitHub code scanning. The composite action writes per-tool reports under agentsec-sarif/ by default.

Known limits

Heuristic scanner, not a security boundary. A clean result does not mean something is safe. All example secrets in this repository are fake.

Full source, tests, and fixtures: tools/yolocheck/ in the repository. Install the kit with pip install git+https://github.com/dunkleschitz/agentsec.git.
