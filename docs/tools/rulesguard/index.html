rulesguard: detect backdoors in AGENTS.md and rule files in AI agents

Offline, stdlib-only Python 3 CLI that scans AI-agent instruction / rules files for "rules file backdoor" style risks: hidden Unicode, instructions to hide actions from the user, injected scripts/dependencies, weakened security, secret exfiltration, curl|sh, jailbreak phrasing, fake chat delimiters, encoded blobs, hidden HTML comments, over-broad Cursor .mdc scopes, remote "fetch and follow" includes, markdown exfil beacons, and permission-bypass instructions.

What it detects

Usage

python3 rulesguard.py [PATH ...]                 # default "."
    python3 rulesguard.py repo/ --json
    python3 rulesguard.py repo/ --sarif > rulesguard.sarif   # SARIF 2.1.0
    python3 rulesguard.py repo/ --min-severity medium
    python3 rulesguard.py repo/ --fail-on medium     # high (default) | medium | low | any | none
    python3 rulesguard.py repo/ --disable RG09,RG11

Exit codes: `0` no findings at/above `--fail-on`, `1` findings at/above it, `2` errors (missing path, unknown rule id).
Snippets are shown with line numbers, invisible characters rendered as `<U+XXXX>`, and secret-looking values masked.

After pip install of the kit, the same options work as agentsec rulesguard …. Every tool also accepts --help and almost every tool accepts --json.

SARIF and CI

agentsec rulesguard path/to/input --sarif > rulesguard.sarif

# GitHub Actions (composite action ships with the repo)
- uses: dunkleschitz/agentsec@v0
  with:
    tools: rulesguard
    paths: path/to/input
    fail-on: high

SARIF 2.1.0 can be uploaded to GitHub code scanning. The composite action writes per-tool reports under agentsec-sarif/ by default.

Known limits

  • Heuristic and string/regex-based. Expect false positives and false negatives.
  • It cannot judge intent: a security guide that *quotes* curl | sh as a bad example will be flagged.
  • Paraphrased, translated, split-across-lines, or otherwise obfuscated instructions can evade it.
  • It does not fetch remote includes, follow imports (@file), or model how a given agent loads rules.
  • A clean result is not proof of safety. It is a triage aid, not a substitute for human review of

everything your agents are told to do.
