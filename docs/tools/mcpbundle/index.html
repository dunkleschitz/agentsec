mcpbundle: detect risky install manifests for MCP servers in AI agents

Offline auditor for MCP server packaging manifests: MCP Bundle manifest.json files (inside a .mcpb archive, the legacy .dxt format, or loose) and MCP Registry server.json entries.

What it detects

Offline auditor for MCP server packaging manifests: MCP Bundle manifest.json files (inside a .mcpb archive, the legacy .dxt format, or loose) and MCP Registry server.json entries.

These are the files an MCP server author ships so a client can install the server in one click. The client trusts them to decide what command to run, which package version to fetch, which settings to ask the user for, and where to send tokens. mcpbundle reads them before you install or publish and flags inline secrets, credential prompts that are not marked sensitive, shell-wrapped or pipe-to-shell launch commands, unpinned packages, cleartext or internal remotes, privileged container arguments, whole-disk directory defaults, injection-shaped tool text, and missing provenance.

Standard library only. It never installs anything, never extracts archives to disk (it reads manifest.json from the zip in memory), and never contacts a registry.

Usage

python3 mcpbundle.py examples/risky                 # text report, exit 1 (high+ findings)
python3 mcpbundle.py examples/clean --min-severity low
python3 mcpbundle.py my-server.mcpb                 # reads manifest.json from the archive
python3 mcpbundle.py . --json                       # walk a repo for manifest.json / server.json
python3 mcpbundle.py server.json --sarif > mcpbundle.sarif
cat server.json | python3 mcpbundle.py -
python3 mcpbundle.py --list-rules

After pip install of the kit, the same options work as agentsec mcpbundle …. Every tool also accepts --help and almost every tool accepts --json.

SARIF and CI

agentsec mcpbundle path/to/input --sarif > mcpbundle.sarif

# GitHub Actions (composite action ships with the repo)
- uses: dunkleschitz/agentsec@v0
  with:
    tools: mcpbundle
    paths: path/to/input
    fail-on: high

SARIF 2.1.0 can be uploaded to GitHub code scanning. The composite action writes per-tool reports under agentsec-sarif/ by default.

Known limits

  • Static review only. A manifest that passes can still ship a malicious

server/index.js; mcpbundle does not read or execute server code (use mcpsink for Python MCP server source).

  • Secret detection is name- and shape-based; it misses secrets with innocuous names

and may flag long non-secret values under credential-like names.

  • Injection detection is a small phrase list plus hidden-Unicode checks, not a model.
  • It does not check that a package version actually exists, that file_sha256

matches the archive, or that the repository is genuine.

  • Only the first manifest.json (shallowest path) in an archive is read.
