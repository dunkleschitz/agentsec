rundiff: detect behavioral drift between agent runs in AI agents

Offline behavioral diff for two AI agent run transcripts.

What it detects

Offline behavioral diff for two AI agent run transcripts.

You changed a system prompt, swapped a model, or added a tool. Did the agent's *behavior* change? rundiff compares a baseline run and a candidate run and tells you which tool calls were added, removed, or reordered, which arguments changed, where tool results diverged, how similar the final answers are, and, for security review, what new surface the candidate touches (new tools, network hosts, filesystem paths, shell programs).

Single file, Python 3 standard library only, no network access, no dependencies.

Rules

exitmeaning
0no difference of the gated kind (always 0 with --fail-on none, the default)
1--fail-on condition met
2error (unreadable file, invalid JSON, bad arguments)

Usage

python3 rundiff.py BASELINE CANDIDATE [--format auto|openai|anthropic|generic]
                   [--ignore-keys k1,k2,glob*] [--json] [--no-color]
                   [--fail-on any|new-surface|args|none]

After pip install of the kit, the same options work as agentsec rundiff …. Every tool also accepts --help and almost every tool accepts --json.

Example output

The bundled examples/ pair: the candidate drops list_dir, changes search_docs.limit from 5 to 20, curls ./docs/RELEASE.md to an unfamiliar paste host, and writes a file with a new write_file tool.

With --fail-on new-surface (or any, or args), this example exits 1. Comparing a run with itself exits 0.

Captured against the bundled fixtures (fake data only):

SARIF and CI

agentsec rundiff path/to/input --json > rundiff.json
# rundiff does not yet emit SARIF; use --json and keep --fail-on for CI.

# GitHub Actions (composite action ships with the repo)
- uses: dunkleschitz/agentsec@v0
  with:
    tools: rundiff
    paths: path/to/input
    fail-on: high

--sarif is not available on this tool yet (resultguard and toolpoison are reserved as good first issues). Use --json and a --fail-on exit gate instead.

Known limits

Heuristic scanner, not a security boundary. A clean result does not mean something is safe. All example secrets in this repository are fake.

Full source, tests, and fixtures: tools/rundiff/ in the repository. Install the kit with pip install git+https://github.com/dunkleschitz/agentsec.git.
