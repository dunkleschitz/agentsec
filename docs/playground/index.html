Playground

Try five agentsec scanners on pasted text or a sample fixture. The tools run in your browser via Pyodide, the same standard-library Python as the CLI.

No data leaves the browser. Whatever you paste is written only into a WebAssembly filesystem in this tab and scanned locally. This page never posts your input to a server. The only network requests are for the Pyodide runtime (CDN) and the tool scripts already hosted on this site.
